The 2D release: four papers from one blinded catalogue

About 2400 deg² effective area, $r$‑band shapes, one redshift bin; blinded through $n(z)$.

Two independent inference pipelines: configuration space ($\xi_\pm$) and harmonic space ($C_\ell$).

The shear catalogue goes public on acceptance, in the next few months.

  • The four papers — shape catalogue (Hervas Peters), B-mode validation and scale cuts (Daley), $\xi_\pm$ cosmology (Goh), $C_\ell$ cosmology (Guerrini): one catalogue, one blinding scheme, two pipelines.
  • Catalogue release — public once the papers are accepted, in the next few months.
  • One redshift bin — only $r$-band across the footprint, so $n(z)$ comes from a SOM calibration on external deep fields.
  • Blinding — three shifted $n(z)$ realisations; scale cuts and catalogue version frozen before unblinding.
