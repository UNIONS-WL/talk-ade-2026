# Calum's half: survey and astrophysics

A separate deck for the first ~15 minutes of the joint talk, made with
[Lectern](https://github.com/calumhrmurray/lectern) (a visual editor for reveal.js decks), not the house system:
Lectern edits slides on a canvas and records positions as inline styles, which the house checker rejects,
so the two halves are kept as two decks. Cail's deck (`../slides`, `../deck.json`) is untouched.

- Open `index.html` in a browser (arrow keys; `S` for speaker notes), or online at
  https://unions-wl.github.io/talk-ade-2026/calum/
- Published by the last step of `.github/workflows/publish.yml`, which copies this folder next to the
  built house deck.
- The working copy lives in Calum's talks repository; this folder is a copy of the deck and the files it
  uses, refreshed from there.
